Så funkar det

  1. Hitta ett lag nära dig, eller sök upp ditt eget.
  2. Swisha din del direkt till föreningen. Mottagare, belopp och meddelande är redan ifyllda.
  3. Dela målet så att fler kan hjälpa laget hela vägen.

Gillar du idén?

Laglyftet är ett demoprojekt som visar hur föräldrar och släkt kan swisha sin del till laget i stället för att sälja kakor och lotter. Pengarna går direkt till föreningens eget Swish-nummer, aldrig via appen.

  • Fri kod. Allt finns på GitHub med MIT-licens. Använd det, ändra det, bygg vidare.
  • Gratis att köra. Webbplatsen ligger på Netlify och databasen i Supabase, båda på gratisnivå.
  • Mer än demon. Den fullständiga versionen har inloggning för lagledare, egna mål och avstämning mot Swish.
Se koden på GitHub

Är du lagledare?

Laglyftet är gratis för föreningar. Så här kommer ni igång:

  1. Berätta om ert lagFyll i formuläret nedan. Det tar en minut.
  2. Föreningen godkännerVi kontrollerar föreningen och kopplar föreningens eget Swish-nummer. Helt gratis.
  3. Dela länkenFöräldrar, släkt och grannar swishar sin del direkt till föreningen.

Vi använder uppgifterna bara för att kontakta dig om Laglyftet. Läs mer i integritetspolicyn.
